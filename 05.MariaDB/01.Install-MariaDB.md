## MariaDB 10.11 Installation:

The 10.11 series is a long-term support branch focused on production stability, compatibility, and operational reliability, with version 10.11.16 released as a stable GA update in February 2026.


### Download and Install: 

_Downloads MariaDB:_
```
wget https://dlm.mariadb.com/4563100/MariaDB/mariadb-10.11.16/yum/rhel/mariadb-10.11.16-rhel-8-x86_64-rpms.tar
```


```
tar -xvf mariadb-10.11.16-rhel-8-x86_64-rpms.tar
```


```
cd mariadb-10.11.16-rhel-8-x86_64-rpms
```



_Disable default MySQL/MariaDB module:_
```
dnf module list mariadb mysql 
dnf module disable mysql mariadb -y

dnf clean all
```




_Install required RPMs for MariaDB Server:_
```
dnf install -y \
MariaDB-common-10.11.16-1.el8.x86_64.rpm \
MariaDB-shared-10.11.16-1.el8.x86_64.rpm \
MariaDB-client-10.11.16-1.el8.x86_64.rpm \
MariaDB-server-10.11.16-1.el8.x86_64.rpm \
MariaDB-backup-10.11.16-1.el8.x86_64.rpm \
MariaDB-compat-10.11.16-1.el8.x86_64.rpm \
galera-4-26.4.25-1.el8.x86_64.rpm
```


```
rpm -qa | grep -i mariadb
rpm -qa | grep -i galera
```


```
mariadb --version

mariadb  Ver 15.1 Distrib 10.11.16-MariaDB, for Linux (x86_64) using readline 5.1
```


```
mariabackup --version

mariabackup based on MariaDB server 10.11.16-MariaDB Linux (x86_64)
```



#### Start and enable service:

```
systemctl start mariadb
systemctl enable mariadb
systemctl status mariadb
```


_Verify listening port:_
```
netstat -tlpn | grep 3306
```


```
mariadb -u root -e 'SELECT VERSION();'

+------------------+
| VERSION()        |
+------------------+
| 10.11.16-MariaDB |
+------------------+
```



### Secure installation: 

```
mariadb-secure-installation
```
